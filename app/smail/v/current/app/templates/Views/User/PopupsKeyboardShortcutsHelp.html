Souvera Mail talks to every common mail app — Thunderbird, Apple Mail, Outlook, K-9 Mail, FairEmail and others. Enter the server details below there.

Important: you need an app password, not your login password

External programs cannot sign in with your normal Souvera login password — they need their own app password per device.

  1. Click your profile picture at the top-right → Settings
  2. Select Security & devices in the left menu
  3. Under “Create new app password” pick a name (e.g. “Thunderbird laptop”, “iPhone”)
  4. Click Create → the password is shown once
  5. Copy it right away and enter it in your mail client as the password — the username is your email address

One app password per device. If you lose a phone you can revoke only that password from the same menu — every other device stays connected.

Attach an existing mailbox from another provider (web.de, GMX, t-online.de, Gmail, …) so you can read and send everything from Souvera Mail without switching apps.

How to attach an external mailbox

  1. Open Settings → Accounts (top-right avatar → the gear icon inside Souvera Mail).
  2. Click Add account.
  3. Enter the email address of the external mailbox and its password (see notes below for Gmail / Outlook).
  4. Souvera Mail auto-detects the correct IMAP/SMTP settings for major providers. Verify and click Add.
  5. The mailbox now appears in the top-left dropdown; switch between accounts without leaving the app.

Where are the credentials stored?

Your external-provider password is stored encrypted at rest on this Souvera server (per-user key derived from the internal APP_SALT). It is used exclusively to fetch and send mail for that mailbox and is never transmitted to third parties.

Limits

  • Your admin has set a maximum of 3 external mailboxes per user.
  • If Souvera Mail cannot send through the external SMTP server 3 times in a row within 24 hours, the account is automatically deactivated. Ask support (or run occ souvera_mail:external:revoke <uid> <email> --reset) to re-enable.

Popular providers

  • web.de / GMX — enable POP3/IMAP access in the provider's web interface first, then add here.
  • Telekom / t-online.de — you need the "Passwort für E-Mail-Programme", not your general Telekom login.
  • Gmail — requires 2FA on your Google account plus a per-app "App password". Set it up at myaccount.google.com/apppasswords.
  • Outlook / Hotmail — Microsoft disabled classic Basic-Auth in Sept 2024. Use a legacy App Password.
